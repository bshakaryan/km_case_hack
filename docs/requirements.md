# Соответствие кейсу

Основа реализации — кейс «Костанайские минералы» и запрос пользователя: реализовать веб-панель, сервер, БД; нативную и ИИ-части оставить заглушками. Поэтому демонстрационные ответы ИИ и TypeScript-заготовка нативного клиента намеренно не заявляются полноценными интеграциями.

| Требование | Реализация / граница |
| --- | --- |
| Стек из кейса | React/TypeScript, Python/FastAPI, PostgreSQL; React Native обозначен контрактом заглушки |
| Вход по логину и PIN | Демонстрационные учетные записи; серверные сессии и проверка прав |
| Мастер, работник, руководитель, администратор | Ролевые страницы/действия и серверное разграничение доступа |
| Сменная панель и производственная доска | Показатели, список нарядов, поиск и фильтры |
| Плановые/внеплановые наряды | Выбор участка, оборудования, исполнителя/бригады, приоритета и срока |
| Загрузка работников | Текущий наряд, очередь, состояние, показатели исполнителей |
| Прием, очередь, отказ, работа, пауза, завершение, проверка, доработка, закрытие | Контролируемые сервером переходы; причины для отказа, паузы, возврата и отмены |
| Просрочки и уведомления | Вычисляемая просрочка, сохраненные уведомления, фоновый контроль сроков |
| Работа исполнителя | Доступна в веб-панели; самостоятельное нативное приложение не реализуется |
| Фото до/после | Проверка, ограничение размера/числа, JPEG-сжатие, авторизованная выдача |
| Обязательное фото для внепланового завершения | Сервер требует фото «После» до приема отчета |
| Работы, дефекты, материалы | Структурированный отчет с фактическим расходом материалов |
| ИИ-проверка и рекомендация | Явная детерминированная заглушка; компьютерное зрение и модели отсутствуют |
| Финальная приемка мастером | Ручное закрытие с оценкой либо возврат на доработку |
| Аудит | События статусов и изменений с временем, автором и причиной |
| Аналитика и рейтинг | Агрегаты БД, динамика работ, простои, оборудование, материалы, исполнители |
| Управленческие подсказки | Явно помеченная ИИ-заглушка поверх демонстрационной истории |
| Экспорт | Серверная выгрузка с фильтрами; CSV с BOM для Excel и XLSX |
| Справочники | Участки, оборудование, сотрудники, бригады, дефекты, материалы, нормы |
| Не менее 500 нарядов за 90 дней | Начальная история: не менее 520 нарядов плюс текущие задания |
| Минимальный объем справочников | 4 участка, 25 единиц оборудования, 2 мастера, 15 работников, 3 бригады, 20 дефектов, 40 материалов |
| Характерные сценарии аналитики | Повторные дефекты конвейеров, проблемы после обслуживания, расход материалов |
| Обновление до 5 секунд | WebSocket и резервный опрос 5 секунд; сетевые SLA нагрузочно не подтверждены |
| Создание за минимальное число нажатий | Компактная форма; целевой лимит нажатий отдельно не измерен |
| Быстрая отправка фото с телефона | Сжатие на сервере; цель по времени передачи в мобильной сети не подтверждена полевым тестом |
| Push и офлайн-режим | Заглушки; нет FCM/APNs, локальной мобильной БД или фоновой синхронизации |
| Русский язык и локальное время | Русские подписи; отображение Asia/Almaty, хранение UTC |
| Воспроизводимый запуск | Docker Compose: PostgreSQL, FastAPI, nginx со сборкой React; локальный режим SQLite |

Проверка функциональности описана в корневом README. Наличие строки в таблице не является результатом нагрузочного теста или заключением о готовности к промышленной эксплуатации.
