# Проверки реализации

## Повторный аудит исходной точки · 5 октября 2026

Версия кода: `322c3d49d5f222337c9e983d4c2b0202ed339f17`. Проверка проведена на Windows, Python 3.12.14, Node.js 24.12.0, pnpm 11.19.0. Для часовых поясов Windows в изолированное окружение дополнительно установлен `tzdata`.

- Все пять `docs/*.md` исходной версии и README прочитаны; сопоставлены сервер, веб, TS-заготовка и исходный PDF кейса (8 страниц, диаграмма на стр. 3 просмотрена отдельно).
- `python -m pytest -q` из `backend/`: **20 passed**, одно предупреждение Starlette о deprecated-алиасе AnyIO. Тестовая БД — SQLite.
- `pnpm install --frozen-lockfile`, `pnpm run build` из `frontend/`: успешно; сборка предупреждает о JS-блоке больше 500 КБ (около 208 КБ gzip).
- `pnpm exec tsc -p ../native-stub/tsconfig.json` из `frontend/`: успешно. Это проверка TS-примера, не сборка мобильного приложения.
- На отдельной одноразовой SQLite-БД воспроизведены: немедленное уведомление новому исполнителю о непринятии после переназначения старого наряда; отсутствие завершённого в периоде переходящего наряда в аналитике; двойной учёт двух совпадающих часовых ремонтов одного оборудования; потеря прежнего шифра/комментария при повторной сдаче с сохранением текстов работ в событиях и расхода материалов.
- По коду отмечен риск блокировки event loop при синхронном SQL и удержании PostgreSQL row lock во время асинхронного чтения фото. Этот конкурентный сценарий на PostgreSQL не воспроизводился.
- В этой повторной проверке **не запускались** Docker/PostgreSQL, браузерные E2E, физические телефоны, реальные ИИ/push, нагрузка или измерения времени. Результаты прежнего раздела ниже не считаются повторёнными.

Новый полный объём и последовательность исправлений: [план](implementation-plan.md), [решения](decisions.md). Тесты исходной точки не означают, что выявленные ошибки исправлены.

## Историческая проверка прототипа · 5 октября 2026

Ниже сохранён предыдущий отчёт без закреплённого SHA. Его ограничения и прежнее решение оставить заглушки относятся к состоянию прототипа, а не к новому полному объёму.

Проверено на Python 3.12, Node.js 24 и PostgreSQL 17.

- Сервер: `pytest -q` — **20 тестов прошли**. Покрыты жизненный цикл, разграничение ролей, изоляция исполнителей, обязательное фото после внепланового ремонта, проверка изображений, защищенная выдача фото, отзыв сессий HTTP/WebSocket, уведомления и пороги эскалации, простой оборудования, безопасность CSV/Excel и целостность справочников.
- Реальный HTTP API с PostgreSQL: `python3 scripts/smoke_api.py` — успешно. Проверена цепочка создания, принятия, начала, отчета с фотографией и приемки мастером, история, записи справочника после seed и действительная структура XLSX.
- `tsc -b` и production-сборка Vite — успешно. TypeScript-контракт `native-stub/` проходит отдельную проверку типов.
- `docker compose up -d --build`: PostgreSQL, FastAPI и nginx/React запущены; все три healthcheck успешны.
- Через браузер пройден полный цикл планового наряда от создания до закрытия с оценкой мастера. Проверены фильтрация оборудования по участку, показ загрузки исполнителей, поиск, хронология и маркировка ИИ-заглушки.
- Проверены отчет за текущую смену, графики и режим руководителя без кнопок создания; вход и выход работают через nginx на порту 8080.
- Интерфейс проверен при ширине 1440 и 390 пикселей. На мобильной ширине документ не имеет горизонтального переполнения; канбан прокручивается внутри своего блока.
- Начальная миграция Alembic проверена на пустой SQLite-базе; PostgreSQL SQL для начальной схемы успешно сгенерирован. Работа ORM с реальной PostgreSQL отдельно проверена сквозным тестом.

Оставшиеся предупреждения инструментов: библиотека Starlette выдает предупреждение об устаревшем алиасе AnyIO; Vite сообщает о крупном JavaScript-блоке с графиками (около 208 КБ gzip). Эти предупреждения не мешают сборке или проверенным сценариям.

Проверки выполнялись на синтетических данных. Нагрузочные измерения, испытания в производственной сети и на физических Android/iOS устройствах не проводились. Нативный клиент, доставка push и нейросетевые функции намеренно оставлены заглушками.
